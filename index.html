CTI Agent

Browser agent · Threat intel2026

CTIBaker

Learn a website once with an LLM, then replay it forever with no AI.

  • An LLM drives Chrome one typed step at a time (login, click, paginate, extract) and each working step is saved to a JSON “recipe”.
  • Later runs replay the recipe deterministically. When a site changes, --heal repairs only the broken step.
  • Credentials never reach the model, and a confirm gate stops before any irreversible action.
  • Live web UI with a step timeline, the planner’s reasoning and browser thumbnails, streamed over SSE.

LLM pipeline · Web app2026

Dream Job

Scores real job postings against your résumé, with every point traceable, and drafts applications that can’t invent experience.

  • The LLM never outputs a score. It judges each requirement and quotes the résumé; code computes a weighted, auditable score.
  • A fabrication guard rejects any claim that isn’t a verbatim résumé span, including inflated numbers.
  • Two LangGraph.js graphs stream live progress. Delta polling cut each run’s transfer from 1.1 MB to 39 KB.
  • Exports a tailored résumé and cover letter as .docx or .pdf.
